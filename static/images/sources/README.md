# Expo East preview source

## OpenFlyGo app icon

`openflygo-app-icon.png` is the original 1024×1024 icon from the OpenFlyGo iOS app's AppIcon asset catalog. The website reuses it without redesign or recoloring; resized PNG and ICO derivatives provide the navigation mark, browser favicon, and Apple touch icon.

`expo-east-ue.png` is an unedited 1920×1080 Unreal Engine viewport screenshot captured on September 21, 2026. It shows the real-capture Gaussian scene in the running Expo East application; the simulated drone is part of that view. The engine's screenshot command omits interface overlays without moving the camera.

Both the homepage teaser and Expo East poster use `../expo-east.webp`, generated from this PNG by resizing to 1800 pixels wide and encoding WebP at quality 88. No color adjustment, retouching, or generated imagery is applied. The interactive Spark viewer is separate and retains its own initial camera view.
